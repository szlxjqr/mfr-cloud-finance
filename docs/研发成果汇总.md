## 二、产品灵魂与方法论

**以业务为入口，联动 财务 / 合同 / 账务 / 税务**。业务单（采购 / 差旅 / 报销 / 合同 / 工资 / 资产）审批通过自动反写账务（凭证 / 应收应付），税务取数、综合报表汇聚——各模块不是平行孤岛。

- **联动地基（B 方案）**：后端 `AccountSubject`（28 个权威科目种子）+ `Voucher` / `VoucherEntry`；报销 / 采购 / 工资 / 资产审批通过自动生成凭证（`source_type/source_no` 幂等）；`ledger_service` 由凭证实时汇总；`financial_statement_service` 由 ledger 实时派生三大报表。
- **表结法**：年终无需结转损益凭证，`balance_sheet` 自动把损益类全年累计净额并入「本年利润(3103)」，资产 = 负债 + 权益恒等。
- **现金流量表符号**以「现金方方向」定（借 = 流入 / 贷 = 流出），对方科目仅定 经营 / 投资 / 筹资 活动。

## 六、工程实践

1. **布局规范**：账簿类页统一「左侧 220px 面板 + 拖拽条 + 右侧表格区」；序时账采用全宽表格。
2. **类型安全**：TypeScript 严格模式，`vue-tsc -b` 类型检查 + `vite build` 双重校验（注意：`vue-tsc` 不捕获模板属性结构错误，必须以 `vite build` 收口）。
3. **真实数据**：业务单审批通过自动生成凭证，账簿 / 报表由凭证实时派生，无 Mock 演示数据。
4. **B 方案组件化**：`styles/design-tokens.css` + 6 个全局组件（`EmptyState` / `DataLoader` / `BatchActionBar` / `StatusTag` / `AppIcon` / `KpiTile`），暖色浅色主题。
5. **发票识别管道**：`utils/invoiceParser.ts` 宽松格式无关解析（去后缀白名单 / 兼容 15·18 位税号 / 明细行去强制 `%`）+ OCR 兜底（tesseract.js `chi_sim+eng`，文本层为空时 canvas 渲染→OCR）。纯函数拆至 `invoiceFields.ts` 便于离线单测。
6. **版本管理**：每次功能提交独立 commit，结构清晰可追溯；`pytest` + 发票离线回归守护核心计算。
