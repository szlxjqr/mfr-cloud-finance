# UI 设计与体验评审报告（Audit + Roadmap）

> **评审对象**：mfr-cloud-finance 智慧经营（69 个 view，2 个核心 layout，1 套全局 style）
> **评审日期**：2026-07-24
> **角色**：UI Designer · 单一主理（多 Agent 视角合一输出）
> **方法**：代码审计 + 风格基线对比 + 真实使用场景反推 + 老板过往反馈归纳

---

## 📌 TL;DR — 5 句话结论

1. **品牌色严重不一致**：37 处仍写 `#409eff`（EP 默认蓝），与 design system 的 `#1667ff`（Ant 风格克制蓝）冲突——这是最大、最显眼的体验硬伤。
2. **响应式覆盖率 17%**：69 个 view 只有 12 个含 `@media`，台式场景调好了、老板出差用 iPad 看一眼报表就会"乱"。
3. **节奏离散**：页面 padding 出现 10/12/14/16/18/20/28/32 px 8 种，info-card vs table 间距混用，UI 不「整」。
4. **状态覆盖不足**：空态 46%，加载态 54%——意味着用户首次进任何列表，看到的可能是空白而无指引。
5. **1520 行的 InvoiceInput.vue 单文件** ——「上帝组件」反模式，重构风险高、可测试性差、未来迭代（差旅自动化）会崩。

## 三、设计系统 1.0 草案（4 个令牌组）

### 3.1 颜色令牌（已部分定稿，缺统一用法）

```css
/* ---- 已定义在 style.css，仅需替换硬编码 → 令牌 ---- */
:root {
  /* 品牌（Ant 克制蓝） */
  --brand: #1667ff;            /* 主色 */
  --brand-strong: #0952d4;     /* 文字按压态 */
  --brand-grad: ...;

  /* 语义色阶（EP 默认+收严） */
  --success / --warning / --danger / --info  ✓

  /* 中性色阶 ✓ Ant 灰阶已齐 */
  --bg-app / --bg-surface / --bg-subtle
  --text-strong / --text-base / --text-muted / --text-faint
  --border-soft / --border-soft-2

  /* 缺：图表色板（首屏同色蓝） */
  --chart-1: #1667ff;
  --chart-2: #36b3c7;
  --chart-3: #52c41a;
  --chart-4: #faad14;
  --chart-5: #f759ab;  /* 警示粉，可选 */

  /* 缺：状态色（业务领域） */
  --status-draft: #8c8c8c;
  --status-pending: #faad14;
  --status-approved: #52c41a;
  --status-paid: #1667ff;
  --status-rejected: #ff4d4f;
}
```

### 3.2 间距令牌（4 档）

```css
:root {
  --space-1: 4px;   /* 微小（icon-button gap） */
  --space-2: 8px;   /* 组件内 */
  --space-3: 12px;  /* 行间 */
  --space-4: 16px;  /* 默认页面边距 */
  --space-5: 24px;  /* 模块间 */
  --space-6: 32px;  /* 罕见（顶级分隔） */
}

/* 收敛 → 替换硬编码 padding/margin */
.page { padding: var(--space-4); }
.toolbar { gap: var(--space-2); margin-bottom: var(--space-3); }
```

### 3.3 字号令牌（6 档 + 行高）

```css
:root {
  --fs-xs: 12px;   /* 辅助文案/说明 */
  --fs-sm: 13.5px; /* 表格 */
  --fs-base: 14px; /* 默认 */
  --fs-md: 15px;   /* 标题 3 */
  --fs-lg: 18px;   /* 标题 2 */
  --fs-xl: 22px;   /* 标题 1 / 数字指标 */
  --fs-2xl: 26px;  /* hero KPI */

  --lh-tight: 1.3;
  --lh-base: 1.55;
  --lh-loose: 1.8;
}
```

## 七、长期方向（设计系统 1.0）

1. **设计令牌化**：所有颜色/间距/字号/圆角统一进 `:root` 变量，禁硬编码
2. **组件库化**：6+ 个核心组件抽出（EmptyState / DataLoader / BatchActionBar / StatusTag / AppIcon / KpiTile）
3. **图标统一**：Element Plus icons 已是默认，只需收口一处入口
4. **响应式分层**：
   - ≥1024 桌面（最佳）
   - 768~1023 平板（折叠侧栏 + 表格列裁剪）
   - <768 手机（暂不优化，提示"请用桌面访问"）
5. **暗色模式**：`prefers-color-scheme: dark` 自动切
6. **可访问性**：表单 label/title/aria，焦点环必现
7. **打印样式**：A4 模板化（避免报销单/采购单/合同各写一份）
8. **设计走查表**：每次 PR 后跑一份 10 项 checklist（color/margin/empty/loading...）
